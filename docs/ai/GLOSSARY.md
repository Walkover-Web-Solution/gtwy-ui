# Glossary

| Term (product)                     | Meaning                                                                     | Code name(s)                                                                    | Where                                                                |
| ---------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| Agent                              | A configured LLM assistant (prompt + model + tools)                         | `bridge`, `bridgeId`, `bridge_id`, `allBridgesMap`; API `/api/agent/`           | `store/reducer/bridgeReducer.js`, `config/bridgeApi.js`              |
| Version                            | A draft or published snapshot of an agent's config                          | `version`, `versionId`, `bridgeVersionMapping[agentId][versionId]`, `parent_id` | `config/bridgeApi.js` (`/api/versions/`)                             |
| Publish                            | Promote a version to live                                                   | `PUBLISH_BRIDGE_VERSION`, `published_version_id`                                | `components/modals/PublishBridgeVersionModal.js`                     |
| Org / workspace                    | A tenant; every route is scoped to it                                       | `org_id`, `orgReducer`, `currentOrgId`                                          | `app/org/[org_id]/`                                                  |
| Role                               | Member permission in an org; `Viewer` is read-only                          | `role_name`                                                                     | `userDetailsReducer.organizations[org_id]`                           |
| Service                            | An LLM provider (openai, anthropic, groq, …)                                | `service`, `SERVICES`, `serviceReducer`                                         | `utils/utility.js#getIconOfService`                                  |
| Model                              | A specific model under a service                                            | `model`, `serviceModels`                                                        | `modelReducer`, `config/modelApi.js`                                 |
| API key                            | The customer's provider key stored in GTWY                                  | `apikeys`, `apikey_object_id`                                                   | `apiKeysReducer`, `app/org/[org_id]/apikeys`                         |
| Pauthkey                           | GTWY's own auth key for calling agents over the API                         | `pauthkey`, `authData`, `authDataReducer`                                       | `app/org/[org_id]/pauthkey`, `config/authApi.js` (`/api/c/authkey`)  |
| Tools / functions                  | Callable actions an agent can use                                           | `functions`, `tools`, `getAllFunctions`                                         | `config/utilityApi.js` (`/api/tools/`)                               |
| Pre-tool                           | A tool that runs before the model call                                      | `preTools`, `PRE_TOOL_TYPES`                                                    | `utils/enums.js`                                                     |
| Prebuilt tools                     | Built-in tools such as web search                                           | `getPrebuiltToolsAction`, `/api/tools/inbuilt`                                  | `bridgeAction.js`                                                    |
| MCP server                         | External tool server attached to an agent                                   | `McpServerList`, `McpServerModal`                                               | `components/configuration/configurationComponent/`                   |
| Connected agents / orchestral flow | Agent-to-agent delegation graph                                             | `connected_agents`, `orchestralFlowReducer` (`orchetralFlow`)                   | `components/AgentToAgentConnection.js`, `ConnectedAgentFlowPanel.js` |
| Variables                          | `{{name}}` placeholders in prompts, filled at runtime                       | `variables`, `VariableMapping`, `extractPromptVariables`                        | `variableReducer`, `utils/variableValidation.js`                     |
| Knowledge base / RAG               | Uploaded docs used for retrieval                                            | `knowledgeBase`, `rag`, `resource`                                              | `config/knowledgeBaseApi.js`, `app/org/[org_id]/knowledge_base`      |
| Embed / GTWY embed                 | GTWY UI in a customer iframe                                                | `embed`, `isEmbedUser`, `embedUserDetails`, `embed_token`                       | `app/embed/`, `public/gtwy.js`                                       |
| Integration                        | An embed configuration (folder) with theme and options                      | `integration`, `folder_id`, `integrationReducer`                                | `app/org/[org_id]/integration`                                       |
| Chatbot                            | Hosted chat widget bound to agents                                          | `ChatBot`, `chatbot_token`                                                      | `config/chatbotApi.js`, `app/org/[org_id]/chatbotConfig`             |
| Thread / history                   | Conversation logs per agent                                                 | `thread_id`, `subThreads`, `historyReducer`                                     | `app/org/[org_id]/agents/history/[id]`                               |
| Execution trace                    | Step-by-step view of one agent run                                          | `executionTrace`                                                                | `components/historyUi/executionTrace/`                               |
| Test case                          | Saved input and expected output to evaluate an agent                        | `testcase`, `testCases`, `testRuns`                                             | `app/org/[org_id]/agents/testcase/[id]`                              |
| Dry run                            | Test execution from the configuration page                                  | `dryRunReducer`, `dryRunAction`                                                 | `store/`                                                             |
| Rich UI                            | JSON UI trees returned by models, rendered as components                    | `richUI`, `RenderNode`, `componentRegistry`, `rich_ui_templates`                | `components/richUI/`                                                 |
| Jev / TypeSafe                     | `typesafe` evaluation service that answers configured questions about input | `JEV_SERVICE`, `isJevService`, `useJevQuestions`                                | `utils/jevQuestions.js`                                              |
| GTWY agent (public/private)        | Marketplace-style published agents                                          | `gwtyAgent`, `runagents`, `page_config.availability`                            | `store/reducer/gwtyAgentReducer.js`                                  |
| Proxy token / local token          | Auth tokens for the proxy service vs the GTWY backend                       | `proxy_token`, `local_token`                                                    | `utils/interceptor.js`                                               |
| Focus mode                         | Layout state that hides chrome on the config page                           | `isFocus`, `setIsFocusReducer`                                                  | `bridgeReducer`                                                      |
| Plan / wallet / credits            | Billing                                                                     | `planReducer`, `walletReducer`, `lago`                                          | `config/billingApi.js`, `config/walletApi.js`                        |
